# editorial annotation

!!! info "Description"
	An editorial annotation is a premeditated mark, usually printed on a musical score by an editor or by the composer themselves. A [musical expression](https://nicholascornia89.github.io/faam/entity/D6RjeTWv) mark such as _espressivo_ in a 19th century edition of a Renaissance polyphonic piece is an example of editorial annotation.
