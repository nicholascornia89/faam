# musical parameter

!!! info "Description"
	Musical parameters, such as [duration](https://nicholascornia89.github.io/faam/entity/R9hADWGS) or [timbre](https://nicholascornia89.github.io/faam/entity/4AMPVsN8), that a given annotation type influences. For example, the indication for the use of [mute](https://nicholascornia89.github.io/faam/entity/BCLeS5SR/) effects the musical parameter of [timbre](https://nicholascornia89.github.io/faam/entity/4AMPVsN8).
