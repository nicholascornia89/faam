# score format

!!! info "Description"
	Complexity level of a manifestation according to its layout.
	- [Full Score](https://nicholascornia89.github.io/faam/entity/XyayZhMR): A combination of several voices and staves in one system, like a song or an orchestral score.
	- [Text](https://nicholascornia89.github.io/faam/entity/KEwR4rEs): Only textual information, without musical notation.
	- [Music Treatise](https://nicholascornia89.github.io/faam/entity/FYtu6ya8): Combination of text and music, typical of music treatises and methods.
	- [Polyphonic Parts](https://nicholascornia89.github.io/faam/entity/ZQLNVHnN): A score for one instrument that uses more than one staff for embedding its voices, like a keyboard or a harp.
	- [Parts](https://nicholascornia89.github.io/faam/entity/guXbuHaq): A voice is embedded in one single staff, usually a melodic instrument.
